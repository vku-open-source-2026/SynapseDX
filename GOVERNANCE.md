# Governance

synapsedx is a community project under Apache-2.0.

## Roles
- **Contributors**: anyone with a merged PR.
- **Maintainers**: review + merge rights, cut releases. Listed in `MAINTAINERS` (initial: project bootstrap team).
- Decisions by lazy consensus on PRs/issues; contentious changes require 2 maintainer approvals.

## Releases
- SemVer. Tags `vX.Y.Z` trigger `release.yml` (GitHub Release + container images).
- `CHANGELOG.md` updated per release.
