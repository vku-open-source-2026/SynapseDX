# Contributing to SynapseDX

SynapseDX is Apache-2.0 software maintained by VKU.VIC. Read `AGENTS.md` for
the public-tier dependency contract. Build with `npm ci && npm run build`, add
tests for behavior changes, and keep dependencies unmodified. Use the public
GitHub issue tracker for bugs and proposals; pull requests must retain SPDX
headers, `NOTICE`, and changelog entries for user-visible changes.
