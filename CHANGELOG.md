# Changelog

All notable changes to this project will be documented in this file.
Format based on Keep a Changelog; versioning follows SemVer.

## [0.1.0] - 2026-10-06
### Added
- Tier-1 PaaS MVP: gateway, IAM (AWS-style org/account/role/policy + tokens + OIDC config), core data (Postgres/Redis/S3), workflow-service over n8n + templates.
- SDKs: `@olp/sdk` (JS/TS), `olp-sdk` (Python), `olp-sdk-go` (minimal).
- Docker Compose topology, service Dockerfiles, K8s base manifests, GitHub CI/release workflows.
- Docs: architecture, IAM model, API reference, quickstart; OSS files: LICENSE (Apache-2.0), NOTICE, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, GOVERNANCE.
